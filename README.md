# Перо

Локальная мастерская короткого рассказа. Рассказ пишет не одна нейросеть, а
целая редакция ИИ-агентов, и вы ведёте её по шагам: выбираете жанровый микс,
правите концепцию и план, следите, как пишется каждая сцена, и решаете, что
оставить.

Всё работает на вашем компьютере. Сервер на Node.js не нужно собирать, у него
нет зависимостей, а все данные лежат в папке `data/`. Наружу программа
обращается только к [OpenRouter](https://openrouter.ai), через ваш собственный
ключ, поэтому можно выбрать любую модель: Claude, GPT, Gemini, DeepSeek, Grok и
другие.

## Быстрый старт

1. Установите [Node.js](https://nodejs.org) версии **20 или новее**.
2. Скачайте проект и в его папке выполните:

   ```bash
   npm start
   ```

   `npm install` не нужен: внешних пакетов нет. На Windows можно просто
   дважды щёлкнуть `start.bat`, на macOS и Linux — запустить `./start.sh`.
3. Откроется браузер с адресом `http://localhost:3000`. Если порт занят,
   программа возьмёт следующий свободный и напечатает его адрес в консоли.
4. Откройте **«Настройки»**, вставьте ключ OpenRouter
   ([получить ключ](https://openrouter.ai/keys)) и нажмите «Проверить ключ».
5. Выберите модель по умолчанию и, если нужно, отдельные модели для разных
   ролей.

Чтобы остановить программу, нажмите `Ctrl+C` в консоли.

## Как пишется рассказ

Мастер состоит из семи шагов:

| Шаг | Что происходит |
|---|---|
| 1. Контекст | Самостоятельный рассказ (выбираете жанр) или рассказ антологии (жанр и лорбук наследуются) |
| 2. Микс | До трёх поджанров. Несовместимые блокируются, поджанр-мост снимает конкретный конфликт. Ползунки весов всегда дают 100% |
| 3. Тон и оптика | Тон (отфильтрован по поджанрам), темп (3–5 сцен), точка зрения, длина сцен |
| 4. Ядро | Конфликт, 1–2 тропа, герои из лорбука и новые, завязка, тип финала |
| 5. Концепция | **Идеолог** превращает завязку в логлайн, тему, героя и противостоящую силу. Всё правится руками |
| 6. План | **Архитектор** строит карточки сцен и назначает каждой писателя. **Сюжетный ревизор** проверяет план, и его можно переписать по замечаниям |
| 7. Рукопись | Каждая сцена проходит конвейер агентов, текст печатается на экране по мере генерации |

После рукописи открывается читалка. **Рецензент** ставит оценку, предлагает
названия и аннотацию. **Архивариус** находит новых героев и места, их можно
одним нажатием сохранить в лорбук антологии. Готовый рассказ скачивается в
`.md` или `.txt`.

## Команда агентов

```
Идеолог → Архитектор → Сюжетный ревизор → (вы правите план)
  ↓ для каждой сцены
Оркестратор → Жанровый писатель → Критик сцены (канон + бета-ридер) → Редактор
  ↓ по готовому рассказу
Рецензент + Архивариус (одним вызовом)
```

| Агент | Роль |
|---|---|
| Идеолог | Концепция: логлайн, тема, главный вопрос, герой с противоречием, антагонист, мотивы |
| Архитектор | План из 3–5 сцен с целью, поворотом и ведущим писателем для каждой |
| Сюжетный ревизор | Проверяет причинность, нарастание ставок, «ружья», соответствие финалу |
| Оркестратор | Без модели: берёт промпт ведущего писателя и вмешивает второй голос в дозе его веса, усредняет temperature |
| Жанровые писатели (30) | Свой голос, словарь, ритм, табу и ориентиры у каждого поджанра |
| Критик сцены | Один вызов за двоих. Хранитель канона ищет фактические нестыковки с лорбуком и прошлыми сценами, бета-ридер читает как читатель: где скучно, непонятно, штампованно |
| Редактор | Точечно правит черновик по замечаниям критика и сглаживает стык голосов. Если нестыковок нет и бета-ридер ставит 8 из 10 и выше, не вызывается |
| Рецензент | Итоговая оценка, сильные и слабые стороны, варианты названия, аннотация |
| Архивариус | Новые сущности для лорбука антологии; ищет их тем же вызовом, что и Рецензент, или отдельно по кнопке |

Новые относительно исходной идеи агенты: Идеолог, Сюжетный ревизор, Хранитель
канона, Бета-ридер и Рецензент. Все, кроме Архитектора и писателей, отключаются
в настройках: каждый агент — это лишний вызов модели, и без них рассказ
пишется быстрее и дешевле.

## Настройки

- **Ключ OpenRouter** хранится в `data/settings.json` на вашем диске (права
  `600`) и в браузер никогда не отдаётся, интерфейс видит только маску.
  Переменная окружения `OPENROUTER_API_KEY` важнее ключа из файла.
- **Модель по умолчанию.** Есть быстрый выбор и поиск по полному списку
  OpenRouter с ценами за миллион токенов и размером контекста. Можно ввести и
  любой свой идентификатор.
- **Модели по ролям.** По умолчанию писатели работают на
  `anthropic/claude-sonnet-5.5`, а критик сцены, сюжетный ревизор, рецензент
  и архивариус — на `google/gemini-3.8-flash`. Остальные роли идут на модель
  по умолчанию. Любую роль можно переназначить.
- **Агенты.** Каждого можно включить или выключить.

Расход токенов и деньги считаются для каждого рассказа отдельно, данные берутся
из ответов OpenRouter.

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `HOST` | `127.0.0.1` | Адрес. По умолчанию сервер виден только с этого компьютера |
| `PERO_DATA_DIR` | `./data` | Где хранить библиотеку и настройки |
| `OPENROUTER_API_KEY` | — | Ключ (важнее ключа из настроек) |
| `OPENROUTER_BASE_URL` | `https://openrouter.ai/api/v1` | Другой адрес API |

## Устройство

```
server/
  index.js        запуск, выбор свободного порта, открытие браузера
  app.js          HTTP-сервер: REST, поток событий агентов (SSE), раздача интерфейса
  openrouter.js   клиент OpenRouter: потоковый чат, повторы, понятные ошибки
  agents.js       реестр агентов и их системные промпты
  prompts.js      сборка контекста: библия истории, каст, план, предыдущие сцены
  pipeline.js     задачи: концепция, план, ревизия, сцена, рецензия, лор
  library.js      антологии, лорбук, рассказы; чистка любого ввода
  settings.js     ключ, модели, переключатели агентов
  store.js        JSON-файлы с атомарной записью
shared/           общий код сервера и браузера
  catalog.js      жанры, поджанры с голосами писателей, опции мастера
  compatibility.js  CompatibilityResolver: блокировки и мосты
  weights.js      веса микса (ровно 100%)
  orchestrator.js раскладка сцен и синтез промпта писателя
  story.js        модель рассказа и проверки шагов мастера
public/           интерфейс без сборки: HTML, CSS, ES-модули
test/             тесты (node:test) с поддельным OpenRouter
```

Данные хранятся в `data/library.json` (антологии, лорбуки, рассказы) и
`data/settings.json`. Чтобы сделать резервную копию, достаточно скопировать
папку `data/`.

**Безопасность.** Сервер слушает только `127.0.0.1`. Запросы с чужим `Host`
отклоняются (защита от DNS-rebinding), изменяющие запросы с чужим `Origin` и
не в формате JSON — тоже (защита от CSRF). Страница работает под строгим
Content-Security-Policy.

## Разработка

```bash
npm run dev   # перезапуск сервера при изменении файлов
npm test      # тесты ядра, клиента OpenRouter и всего HTTP-конвейера
```

Тесты не ходят в сеть: `test/helpers.js` поднимает поддельный OpenRouter,
который отвечает за каждого агента и умеет отдавать ответ потоком.
